# Reachability sweep allowlist (scripts/ci/reachability-sweep.sh).
#
# Every entry below carries a mandatory inline reason (enforced by this
# repo's plan verification, not by the sweep script itself) because an
# entry without one is exactly how a real defect gets silently permitted
# later. Two categories exist here, and the reason says which:
#
#   (a) Genuinely reflective/dispatched call paths -- @main entry points,
#       GenServer callbacks, Elixir __using__ macros -- where the grep
#       heuristic structurally cannot see the caller. These are NOT gaps.
#
#   (b) Genuinely unreachable production code, disclosed here rather than
#       silently permitted. Baselining this sweep for 04-18 (playstead
#       .planning/phases/04-persistent-save-continuity/04-18-PLAN.md)
#       surfaced real, previously-undocumented wiring gaps -- most
#       significantly, the entire save-capture-and-upload pipeline
#       (SaveCapturePoller/SaveUploadLane) has no production trigger at
#       all. Fixing these is out of this gap-closure plan's declared
#       scope (front-door journeys + promoting this sweep to a gate); each
#       is written up in 04-18-SUMMARY.md and recorded in
#       .planning/WINDOWS.md so it stays visible instead of disappearing
#       into a clean-looking allowlist. A future plan should shrink this
#       file by fixing the wiring, not by deleting these lines.

# --- (a) Genuinely reflective / dispatched -----------------------------
