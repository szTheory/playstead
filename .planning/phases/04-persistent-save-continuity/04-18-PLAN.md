<objective>
Add the one test dimension this phase was missing: journeys that enter through the front door and reach each save surface the way a person does.

Purpose: The phase shipped eight defects in which a component was built, unit-tested, snapshot-tested AND driven by an XCUITest — and was still unreachable. Every save-related UI test sets a `PLAYSTEAD_UI_TEST_*` flag that has `UITestBootstrap` present the surface directly, so all of them proved behavior and none could see a missing link. `StorageInteractionTests` and `CurationInteractionTests` already navigate without flags, so the capability exists; the save work simply did not use it.

Output: A small set of front-door journeys that fail loudly when a surface cannot be reached, plus the static reachability sweep promoted to a real CI gate with a zero baseline.
</objective>
