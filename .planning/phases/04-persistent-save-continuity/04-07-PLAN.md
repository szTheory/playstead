<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server-provided revision bytes → local `.sav` | Bytes fetched from the server are written into a path a live emulator will mmap |
| adapter-declared contract → restore decision | The adapter, not Playstead, declares what binds and what is provenance |
| concurrent launches → one save artifact | Two launches could otherwise both execute a plan |
| launch flow → network | A network call in the Play flow would break the offline promise SAVE-03 names |
