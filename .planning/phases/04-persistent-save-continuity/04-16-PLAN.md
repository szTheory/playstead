<objective>
Connect the four save-safety surfaces that are built, tested, and unreachable — so the phase's protective features actually protect a user rather than only a test.

Purpose: The D-40 interruptive modal, its export escape hatch, the divergence badge, and the readiness Save row all work correctly in isolation and none of them is reachable from the app. The gate is `count > 0` and every production path supplies zero. The escape hatch — D-40's *default* button, the safe choice — dismisses the sheet and exports nothing, which is worse than having no modal at all because it manufactures false confidence.

Output: Real counts flowing from committed local state into both reclaim surfaces, a working export deep link, a divergence badge with a caller, a readiness engine that knows about saves, and wiring tests that fail if any of those connections is cut again.
</objective>
