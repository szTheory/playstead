## Sampling Rate

- **After every task commit:** Run the changed layer/test identifier with `test-without-building`; build first only when build products are absent.
- **After every plan wave:** Run all four Mac verification layers against fresh DerivedData; include the native live server for the integration layer.
- **Before `$gsd-verify-work`:** The hosted macOS job, Linux server tests, and Compose job must all be green.
- **Max feedback latency:** 15 minutes for the complete hosted Mac job; targeted task checks should finish within 5 minutes.
