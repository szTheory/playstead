## The live-server blocker (root cause found)

The `live-server` layer failed on every run after `aab1a1c`. `unit`, `rendering`
and `ui` are green, and both Linux jobs are green — only checkpoint 2's covering
test, `LiveServerSnapshotTests/testPairedFreshMirrorRendersSnapshot…AcrossRelaunch`,
fails.

Root cause, diagnosed from `FAILURE_STAGE live-server-create-server-control-prepare`:
the fixture's two roots could diverge. `write_failure_stage` was demonstrably able
to create files in `PLAYSTEAD_LIVE_SERVER_STAGE_ROOT` (that is how the stage token
was published) while `mkdir` under `PLAYSTEAD_MAC_CI_ROOT` failed — only possible
if the two point at different directories. `resolvedFixtureEnvironment()` accepted
a fully-populated inherited environment without checking it was self-consistent,
and preflight checked each root exists but never that they match.

Fixed in `18413b1`. If it regresses, the new bounded token is
`live-server-preflight=root-mismatch` — that names the condition directly.

**Do not** resume the pre-`18413b1` pattern of guessing at this failure. Seven
commits (`fa19dd5`…`0c1ce15`) each guessed at environment plumbing without a
diagnostic that could distinguish the candidates. The productive move was
splitting `validate-input` into bounded sub-stages (`ec2e12f`) so the failing
statement named itself.

## Critical Anti-Patterns

| Anti-pattern | severity | Why |
|---|---|---|
| Pushing while a run you need is in flight | blocking | `ci.yml` uses `concurrency: ci-${{ github.ref }}` with `cancel-in-progress: true`. A docs commit cancels the run you are waiting on. Commit locally; push after it lands. |
| Trusting a gate that passes only its own fixtures | blocking | `validate_roadmap` asserted a ROADMAP shape that does not exist in this repo and still passed its suite. Every gate must be exercised against the real file it guards. |
| Guessing at a bounded-evidence failure | blocking | Bounded evidence omits messages and paths by design. When a stage token is too coarse to identify the failing statement, split the stage — do not guess. |
