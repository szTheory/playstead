## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| GitHub workflow → hosted runner | Repository code executes on a mutable third-party image. | Source, build inputs |
| UI test → scoped Keychain | Test credentials cross Security.framework without entering shared login state. | Device credential |
| Hosted results → adoption decision | Untrusted remote metadata/artifacts must bind to one authorized run and exact commit. | Run identity, evidence |
| XCTest/servers → evidence staging | Raw output may contain secrets, paths, labels, or content metadata. | Logs, xcresults |
| Manual refresh → committed baselines | Candidate rendering must not become repository truth without review. | Snapshot images |
| Profile selector → production stores | Finite test input controls real local persistence APIs. | Profile name |
| UI-testing build → Release product | Test-only composition must not cross into shipping code. | Compiled symbols |
| Production views → reference images | Rendered fixtures become reviewed repository artifacts. | Synthetic fixtures |
| XCUITest → live tree | Rendered untrusted labels/frames may enter diagnostics. | Accessibility tree |
| UI reorder → store/outbox | Gesture/command creates durable local mutation. | Order rows, outbox |
| Storage UI → local files/rows | User controls can alter cached bytes but not canonical catalogue state. | Cached blobs |
| XCUITest → public HTTP | Pairing/snapshot crosses real auth and authorization. | Pairing code, token |
| Handoff → Keychain → API client | Credential is transient then normally loaded. | Device credential |
| Local repository → GitHub remote | Final publication is an external mutation requiring explicit user authority. | Commits |
| Hosted evidence → canonical planning records | Remote run conclusions determine which UAT claims advance. | Run conclusions |
| GitHub run/artifact → adoption record | Remote metadata and artifacts may be stale, unrelated, incomplete, or maliciously malformed. | Run JSON, manifest |

## Audit Notes

**Two threats were initially OPEN and were fixed rather than accepted.**

T-03.5-01 and T-03.5-20 both depend on `verify_complete_hosted_run`, which was
fully implemented and correct but reachable only through a CLI flag that nothing
invoked. CI uploaded `complete-verification-evidence.json` and no automated step
ever checked that the artifact belonged to the run claiming it.

The distinction that made these blocking: T-03.5-22/23/24 name *human
observation* as their control, and the summaries show those checkpoints were
genuinely exercised — so human execution is the mitigation. T-03.5-01 and
T-03.5-20 instead describe an automated fail-closed validator with no human
carve-out, so an opt-in CLI was a weaker control than the register claimed.

Closed by `e50a12f`, which adds `.github/workflows/verify-hosted-evidence.yml`.
It cannot run inside `ci` — the validator asserts the run's own conclusion, which
a job cannot observe while its run is in progress — so it triggers on
`workflow_run` completion, downloads the manifest from the triggering run,
derives the run record from the GitHub API view rather than hand-authoring it,
and runs the validator with read-only permissions.

Verified against real artifacts from run `33710832760`: the rendered CI step
passes on the correct manifest and exits 1 with `complete evidence identity
mismatch: run_id` when handed run `33702909968`'s manifest. `four-layer-topology-test.sh`
guards the wiring, mutation-tested against all four load-bearing markers.

**Related hardening during this phase's gates.** Three fail-open defects were
found and fixed in the harness that carries several of these mitigations: all
ten static contract guards were unreachable from CI (`665a62f`); the wave6
guard depended on Homebrew ripgrep, absent from the runner image, and would
have passed vacuously there (`541520b`); and the hosted-run validator's own
fixture meta-test was unwired (`66947c2`). A mitigation that exists but never
executes is not a closed threat, and this phase produced three of them.
