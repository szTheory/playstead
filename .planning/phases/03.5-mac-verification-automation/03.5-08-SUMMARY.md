## Decisions Made

- Use fixed public synthetic non-ROM sentinel bytes. They exercise custody and snapshot behavior without importing user content or creating a ROM-acquisition path.
- Keep the credential handoff one-use. Bootstrap validates ownership/mode/size, deletes it before Keychain storage, and refuses any credential override on relaunch.
- Keep Phoenix as the only HTTP listener. Mix fixture tasks reuse the database/domain contexts but disable their own endpoint to avoid port contention.
- Pass native runtime values explicitly through the LiveServer test plan. Hosted Xcode process inheritance is not a correctness contract.
- Publish only allowlisted failure-stage identity. Raw fixture stderr, Phoenix logs, credentials, database files, absolute paths, and sentinel bytes remain inside the ephemeral runner root.
