## CI Test Topology

| Option | Description | Selected |
|--------|-------------|----------|
| Monolithic live-server journey | One XCUITest flow owns all five UAT claims; realistic but slow, order-dependent, opaque, and unable to create every deterministic state cleanly. | |
| Layered single macOS job | Build once; run unit, rendering, deterministic UI/accessibility, and focused live-server layers independently on one isolated runner. | ✓ |
| Parallel macOS jobs | Shorter wall time but duplicated builds, environment skew, signing/artifact-transfer complexity, and greater macOS runner consumption. | |
| Mocked HTTP only | Fast and deterministic but cannot prove real pairing or `/api/v1/snapshot` reaches the launched app. | |

**User's choice:** Approved the synthesized recommendation as a set.
**Notes:** The GitHub-hosted `macos-*` decision was already locked. Research found that standard hosted macOS cannot run Docker Compose, so Linux keeps deployment evidence while macOS runs Phoenix/PostgreSQL natively for client behavior. No paid larger runner or network tunnel is introduced.

## Pairing and Deterministic State

| Option | Description | Selected |
|--------|-------------|----------|
| Automate every production UI | Drive setup, Devices approval, import, and Mac UI; maximal ceremony fidelity but duplicates existing browser coverage and multiplies flake sources. | |
| Direct SQL plus credential injection | Exact and fast but bypasses setup, import, pairing, audit, journal, and Keychain invariants. | |
| `pair-dev.sh` with shared login Keychain | Reuses the local helper but requires manual approval, broad Keychain ACLs, and collision-prone shared state. | |
| Production orchestration plus isolated UI bootstrap | Real domain/API pairing and Keychain with a disposable root plus finite compile-gated profiles for deterministic UI states. | ✓ |

**User's choice:** Approved the synthesized recommendation as a set.
**Notes:** The live sentinel proof must demonstrate snapshot traffic, zero blob traffic, empty cache directories, a nonempty cursor, exact UI data, and credential-backed relaunch. Security-sensitive artifacts are never uploaded.

## Snapshot Contract

| Option | Description | Selected |
|--------|-------------|----------|
| Bitmap snapshots only | Visually direct but unable to prove navigation/status/domain invariants and vulnerable to broad-tolerance false confidence. | |
| Structural assertions only | Precise and fast but cannot make a visual regression fail CI. | |
| SnapshotTesting hybrid | Exactly pinned test-only bitmap tooling behind a local wrapper plus exact semantic invariants and mutation guards. | ✓ |
| Project-owned image comparator | No dependency, but reinvents image normalization, comparison, diff generation, and failure UX with high silent-bug risk. | |

**User's choice:** Approved the synthesized recommendation as a set.
**Notes:** Baselines are targeted, deterministic, reviewed manually, and never auto-recorded. Pixel and semantic claims are kept separate so each test proves only what its evidence can support.

---

## Keyboard and Accessibility Proof

| Option | Description | Selected |
|--------|-------------|----------|
| Layered XCUITest/live-tree contract | Real keyboard focus, live accessibility data, per-screen audits, independent surface inventory, focused drag proof, and exact postconditions. | ✓ |
| Monolithic UI tour | Close to a single user journey but brittle, order-dependent, and poor at diagnosing accessibility failures. | |
| In-process `NSAccessibility` host | Precise for custom AppKit controls but does not prove the launched app, real Tab traversal, sheets, or `.onMove`. | |

**User's choice:** Approved the synthesized recommendation as a set.
**Notes:** Research found real Phase 3 defects: no d-pad/shoulder-to-SwiftUI navigation, missing production routes for documented controls, no implemented shared focus ring, and a partially vacuous manifest audit. Phase 3.5 fixes already-scoped keyboard/reachability defects but splits UAT checkpoint 10 so controller and experiential VoiceOver claims remain unproven.
