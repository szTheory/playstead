## Decisions Made

- Used a generated root rather than accepting a path from the launch environment; the only accepted input is a finite profile name.
- Reused the same opened `LocalStore` in profile seeding and `AppEnvironment`, avoiding a silent second-open fallback and enabling deterministic close-before-delete cleanup.
- Kept local deterministic profiles entirely offline without introducing a credential override or network endpoint.
- Built the Release proof with `CODE_SIGNING_ALLOWED=NO`, eliminating authorization/certificate interaction while still scanning the real optimized executable.
