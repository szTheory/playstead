## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Sequenced native bootstrap before the hosted health probe**

- **Issue:** The initial hosted run raced Phoenix dependency/bootstrap work and could not produce authoritative native health evidence.
- **Fix:** Made bootstrap synchronous and retained bounded diagnostic output.
- **Committed in:** `dfddfe5`

**2. [Rule 1 - Bug] Removed hosted Keychain app-link dependency**

- **Issue:** The UI canary could not link against application-owned Keychain code on the hosted test runner.
- **Fix:** Exercised Security.framework directly against a disposable scoped file-Keychain without altering the login search list.
- **Committed in:** `efeb98b`

**3. [Rule 1 - Bug] Corrected and portableized Xcode test selectors**

- **Issue:** Dot-form selectors and escaped slash forms were rejected or preserved incorrectly by hosted Bash/Xcode.
- **Fix:** Derived target/test selectors with portable parameter expansion.
- **Committed in:** `9188997`, `17c0562`

**4. [Rule 1 - Bug] Isolated deterministic hosted keyboard focus**

- **Issue:** Full Keyboard Access focus order on the production window was nondeterministic on a fresh hosted account.
- **Fix:** Added a DEBUG-only focus canary view and exact forward/wrap/reverse/Space activation assertions; verified it is absent from Release.
- **Committed in:** `64e3a98`

**5. [Rule 1 - Bug] Propagated and bounded snapshot evidence**

- **Issue:** The snapshot output setting did not reach the test process; once propagated, calibrated grayscale fixtures compared as transparent and internal baselines polluted the strict triplet inventory.
- **Fix:** Inherited the scheme environment, used explicit calibrated RGB fixtures, and placed internal SnapshotTesting files under `.snapshot-testing`.
- **Committed in:** `cf8dcd4`, `c9416ff`

**6. [Rule 1 - Bug] Scoped verifier cleanup to prevent RETURN-trap leakage**

- **Issue:** Verification succeeded but a function-level `RETURN` trap survived until the outer runner returned, causing an unbound local variable failure.
- **Fix:** Ran verification in a subshell with a scoped `EXIT` trap and added a topology guard.
- **Committed in:** `fcadbb3`
