<objective>
Close Gap B from `03-VERIFICATION.md` as far as it can honestly be closed today, and make the remainder a single gated step rather than an open-ended deferral.

`PLAY-05` requires launch, exit, and relaunch "from a signed/notarized Mac build". No genuinely notarized artifact has ever been produced - builds were dev-signed only, a deliberate and disclosed owner decision on 2026-08-30 to skip paid Apple Developer Program enrolment. `scripts/sign-and-notarize.sh` supports notarization but has never run against a real Developer ID Application identity, and its current shape *degrades gracefully* to signature-verification-only when no credential profile is set - which is exactly the fail-open shape that lets an unnotarized build look like a clean release run.

**PLAY-05 stays open until the checkpoint in Task 2 clears.** This plan cannot and does not close it by code. What it does close: the release path becomes one end-to-end command that refuses to certify an unnotarized build, that refusal is proven in both directions by a guard test, and every downstream document, UAT item, and requirement row flips the moment a real identity exists - with no further design work.

Purpose: convert an indefinite deferral into a single blocking external action with everything else already built and proven.
Output: an end-to-end release verification command, a two-direction preflight guard, a blocking enrolment checkpoint, and the evidence-and-documentation flip that runs after it.

**Scope fence.** This plan closes Gap B only. Gap A (BIOS reference wiring) belongs to `03-11-PLAN.md`. CR-01/CR-02 are recorded `status: resolved` in `03-VERIFICATION.md` and get no work here.
</objective>
