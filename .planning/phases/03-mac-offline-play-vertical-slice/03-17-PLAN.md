<interfaces>
ControllerInputSource currently exposes currentControllers plus startObserving(onConnect:onDisconnect:). ControllerHost owns connectedControllers, assignedControllerID, liveInputs, showRecoveryBanner, assign(controllerID:), and reportInput(_:active:). Extend this boundary with production input events rather than adding a second controller host.

ControllerDescriptor.id currently conflates a run-local ObjectIdentifier-derived instance id with ControllerMapping.controllerProductID. Separate those concepts: the instance id distinguishes simultaneous devices; a stable model key persists the mapping. Identical devices may deliberately share a model mapping, but that behavior must be explicit and tested.

The existing UI layer is selected through TestPlans/UI.xctestplan and run_test_layer ui in scripts/ci/run-mac-verification.sh. Required tests use identifiers of the form PlaysteadUITests.ClassName/testMethodName.
