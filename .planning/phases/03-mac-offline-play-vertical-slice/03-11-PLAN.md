## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user filesystem -> BiosStore | A dragged-in file is fully untrusted: arbitrary path, arbitrary bytes, possibly a symlink or a directory, possibly mutated mid-validation |
| public reference source -> 03-BIOS-PIN.json | A digest transcribed from the internet becomes this app's trust anchor for what counts as a genuine BIOS |
| BiosStore managed directory -> emulator process | Managed BIOS bytes are handed to a child emulator process in an app that deliberately ships without App Sandbox |
