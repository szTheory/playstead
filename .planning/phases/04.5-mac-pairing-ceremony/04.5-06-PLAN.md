<design_decision>
**Injectable parameter with a secure default, not a non-optional property.** `APIClient.init`'s `pinnedCertificateURL` stays `URL?` and stays injectable, but its default value changes from `nil` to `AppPaths.defaultPinnedCertificateURL()`.

Rationale: ~18 existing unit-test call sites construct `APIClient(keychain:session:credential:)` against a `StubURLProtocol` session; making the parameter non-optional would churn every one of them for no security gain (those clients never build the pinned session — `sessionOverride` short-circuits the lazy `defaultSession`). Making the *default* the real pinned path inverts the failure mode instead: a future call site that wants no pinning must now type an explicit opt-out, which is visible in review, rather than getting an unpinned client by saying nothing — which is exactly how both current sites regressed.

What stops the next call site from repeating this: (1) the default is secure, so silence now means pinned; (2) `PinnedTrustWiringTests` asserts the two real construction sites by name — the production composition root behaviorally (it constructs the real `AppEnvironment`), and the `UI_TESTING`-gated harness by source assertion, since it is not compiled into the Unit test build.

Both real sites still pass the URL explicitly rather than leaning on the default, because both work against a *scoped* `AppPaths` root in tests and CI; the default only covers the un-scoped production path.

Reversibility: `reversible`. Changing a default argument and widening two access levels is a one-commit revert with no data-format or on-disk consequence. No `checkpoint:decision` required.
</design_decision>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mac client → Playstead Phoenix server (TLS) | Every authenticated request crosses an untrusted network; the paired device's bearer credential rides in the `Authorization` header. |
| Pairing-time handshake → `pinned-ca.der` on disk | The trust-on-first-use anchor is captured once and persisted at `AppPaths.root/pinned-ca.der` (0600). |
| Platform / login trust store → server-trust evaluation | Any CA present in (or later added to) the system trust store can satisfy default evaluation. |

## STRIDE Threat Register (ASVS L1, blocking threshold: high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
