Those facts make a transient initialization race a hypothesis to test, not a conclusion about this run. The plan must not add error text, credentials, paths, or new receipt fields. If all bounded attempts fail, the Linux restore remains red with the same fixed stage. No dependency, GitHub Action, workflow semantic, SQL seed operation, or sanitizer schema change is permitted.
