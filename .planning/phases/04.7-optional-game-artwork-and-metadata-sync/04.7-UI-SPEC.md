# Phase 04.7 — UI Design Contract

> Native macOS SwiftUI contract for optional private game artwork and metadata enrichment. This extends Phase 3's native library contract; it does not redesign the Phoenix console.

## Scope and source decisions

This contract carries forward all 16 decisions in `04.7-CONTEXT.md`, the five Phase 4.7 success criteria, and META-01. Provider enrichment (IGDB, disabled until explicit consent and self-hoster credentials) and private local media remain separate paths. A lookup shows the exact title/system query and disclosed fields first; hash matching is a separate opt-in. Never disclose filenames as fallback queries, filesystem paths, ROM/save bytes, or play history. Do not ask per ordinary lookup after consent. Whole-library/collection preparation always requires a separate review.

Provider evidence is a suggestion. Selected fields, corrections, candidate choices, and media references are durable synced state; local cache availability is device-local. Low-confidence and competing edits remain unresolved until explicitly selected. Refresh never overwrites a correction. Metadata never changes ROM bytes, manifest identity, save identity, readiness, or launch eligibility.

The detail destination is opened from the existing game row/card More Actions menu as **View Game Details**. Keep the current sidebar and navigation nouns. Provider setup and cache controls live under the existing **Settings** destination. A game detail sheet/pane remains bounded, closes with Escape/B, and returns selection and focus to the same game's View Game Details control. Catalogue screenshots are explicitly labeled **Game screenshot** and never described as progress, a save, or compatibility evidence.

## Design System

| Property | Value |
|----------|-------|
| Tool | Manual native design system; shadcn gate not applicable to SwiftUI/AppKit |
| Component library | SwiftUI and focused AppKit controls; no third-party UI kit |
| Icon library | SF Symbols, using existing native status/readiness vocabulary |
| Font | SF Pro through existing `.psBody`, `.psLabel`, `.psHeading`, `.psDisplay` semantic tokens |
| Color mode | macOS semantic colors and the user's system accent; supports light and dark appearances |

No package inventory applies: the contract uses Apple SDK controls and the project-owned `DesignTokens` layer rather than an installed component package. Reuse `GameRowView`, `SystemMonogramView`, `LibraryShellView`, the focus/navigation bridge, semantic `DesignTokens` colors, and existing accessibility identifier conventions. Do not add a sidebar category for media or install an image UI package.

## Spacing and geometry

All spacing uses existing `DesignTokens.Spacing` values; 1 SwiftUI point equals 1 layout point. Do not add intermediate spacing values.

| Token | Value | Usage |
|-------|-------|-------|
| `xs` | 4 pt | Icon/label gaps, image status badge inset |
| `sm` | 8 pt | Card internal rhythm, metadata line gaps |
| `md` | 16 pt | Detail section gaps, form row spacing |
| `lg` | 24 pt | Content inset and major card padding |
| `xl` | 32 pt | Separation between detail sections |
| `xl2` | 48 pt | Major destination breaks |
| `xl3` | 64 pt | Window-level content inset where existing composition uses it |

| Surface | Fixed geometry |
|---------|----------------|
| Card grid game card | Preserve existing 280 × 224 pt size and 12 pt corner radius |
| Card grid art frame | 44 × 44 pt in the existing system-identity slot; `.scaledToFit`, never crop, on semantic `surface` backing |
| Compact list artwork | 40 × 40 pt; `.scaledToFit`; existing row height and title/action columns remain stable |
| Detail cover | Maximum 240 × 320 pt; preserve source ratio and center within the frame |
| Gallery image | Maximum 720 × 480 pt; preserve source ratio, scroll within the destination |
| Icon-only or gallery navigation target | Minimum 44 × 44 pt; use native focus treatment |

The primary visual anchor for library browsing is the populated game's identity block: its truthful cover beside the game title and system. Keep that identity prominent within the existing card hierarchy, with the existing Play/Continue control as the clearest direct action. Do not enlarge it into a separate hero or let artwork displace readiness, title, or launch controls; the detail destination follows the same identity-first hierarchy at its larger cover size.

Square, portrait, and landscape media use the same frame and retain their full source ratio. Empty/loading frames use the existing system monogram or neutral progress placeholder; never synthesize title-specific artwork. The grid cover reuses the system identity slot, so card height, title/status/action positions, and direct Play/Continue geometry remain unchanged. List rows may replace the monogram with a truthful 40 pt thumbnail but keep all existing text and action regions.

## Typography

Use the existing SF semantic styles, which follow system text scaling. The point values below document the current visual hierarchy; semantic styles remain authoritative if macOS scales them.

| Role | Token | Reference size | Weight | Line height |
|------|-------|---------------|--------|-------------|
| Body | `.psBody` / `.body` | 16 pt | Regular 400 | 1.5 |
| Label | `.psLabel` / `.callout` | 14 pt | Regular 400 | 1.4 |
| Heading | `.psHeading` / `.title3` | 20 pt | Semibold 600 | 1.2 |
| Display | `.psDisplay` / `.title` | 28 pt | Semibold 600 | 1.2 |

Use only Regular (400) and Semibold (600). Card titles keep the established two-line tail truncation and do not gain hover-only tooltips. Descriptions wrap and scroll in the detail destination; buttons retain native sizing and labels at the user's macOS text scale.

## Color

Apply the existing macOS semantic roles and current `DesignTokens` values. The 60/30/10 split describes visual surface area, not hard-coded RGB ratios; the system resolves semantic colors for appearance and contrast.

| Role | Exact token | Approximate share | Usage |
|------|-------------|------------------|-------|
| Dominant | `DesignTokens.background` = `Color(nsColor: .windowBackgroundColor)` | 60% | Library and detail destination background |
| Secondary | `DesignTokens.surface` = `Color(nsColor: .controlBackgroundColor)` | 30% | Cards, image letterbox frames, grouped settings, gallery backing |
| Accent | `DesignTokens.focusRing` = `Color(nsColor: .controlAccentColor)` | ≤10% | Focus ring, selected native control, active gallery position only |
| Destructive | `DesignTokens.destructive` = `#EF4444`; semantic `systemRed` for inline errors | — | Confirmed removal/reclaim actions and actual errors only |
| Primary/muted text | `DesignTokens.textPrimary` = `.labelColor`; `DesignTokens.textMuted` = `.secondaryLabelColor` | — | Titles/body and provenance/helper text |
| Divider | `DesignTokens.border` = `.separatorColor` | — | Section and form separation |

Artwork pixels are content and do not count as interface accent. Never use provider branding or artwork color to signal trust, rights, confidence, or readiness. Status/confidence always includes text or a distinct symbol; color alone never communicates meaning.

## Interaction and disclosure contract

- The card's existing readiness-aware **Play**, **Continue**, or actual remedy stays directly actionable without opening details. Metadata work never becomes a readiness check, disabled launch state, or network prerequisite.
- In Cards view, an art frame is non-actionable content; View Game Details remains a named action in More Actions. In List view, the frame is also non-actionable. Opening details never replaces the primary Play/Continue action.
- Detail order is cover/title and Play/Continue, description, source/match evidence, then representative game screenshot and **View screenshots** gallery action. Readiness and saved-progress history remain on existing routes.
- The detail destination uses native macOS presentation and scrolling. Keyboard Escape and controller B close it; focus returns to the invoking game control. Gallery Left/Right and controller D-pad/shoulders traverse images; Escape/B returns to details. VoiceOver exposes labeled Previous image, Next image, and Close gallery actions. Do not trap focus or require hover.
- Provider setup starts disabled. Before enabling, show IGDB as the selected source, credential requirement, exact proposed title/system query, fields sent, attribution, cache/expiry policy, and the private authenticated-use/redistribution limits. Hash matching appears as its own unchecked choice with a plain explanation. No provider request can occur before consent and credentials are both valid.
- Bulk/offline preparation starts only after an explicit selected-game review showing game count, exact disclosed fields, request upper bound, download estimate, current budget, and provider limits. Minimal fetches description only; Balanced (default) fetches description and cover while browsing and one representative game screenshot on details. Additional gallery images load only on opening the gallery or explicit preparation.
- Keep synced selection/provenance separate from local cached availability. Label a cached asset **Available offline** only while its recorded policy permits local use. Expired/unavailable provider images retain metadata and attribution but show **Image unavailable** with no stale image display.
- Users can add private plain text and PNG/JPEG images. Their canonical originals and provider-derived cache have distinct labels and controls. Cache reclaim can delete only derived, unpinned, refetchable provider media; it never targets game downloads, saves, canonical assets, or private originals.
- Show the provider-media budget as **1 GiB per user**, separate from game and save storage. Show selected-offline media against that same budget. In the preparation review, disclose the per-game ceiling of **32 MiB** for up to eight screenshots; show provider-image refusal if a cover exceeds **8 MiB** or screenshot exceeds **12 MiB**. Private originals have their own visible upload limit of **20 MiB per image** and never count toward or get reclaimed from the provider cache.
- Corrections show field-specific source/version. **Reset to provider** is explicit per field or selection and names the provider version. Conflicts show both values, source/device, and an explicit **Keep this value** choice for each; no last-write-wins presentation.
- Use only purposeful state feedback. No ambient shimmer or animated cover swap. On keyboard/controller actions, update promptly without staging delay. Honor Reduce Motion by replacing transitions with an instant state change; gallery movement remains available without animation.

## Copywriting Contract

| Element | Exact copy or rule |
|---------|--------------------|
| Primary game action | Preserve existing readiness copy: **Play** / **Continue**; this remains the card's direct primary action |
| Detail action | **View Game Details** |
| Gallery action | **View screenshots**; gallery heading **Game screenshots** |
| Empty artwork | Heading: **No artwork yet**. Body: **Add private artwork or choose a provider to enrich this game.** |
| Empty description | **No description available.** |
| Provider request review | **Before lookup**; show the exact query and disclosed fields. Confirm button: **Enable IGDB lookup** |
| Ambiguous match | **Choose a match**. Body: **These results may describe a different release. Review the system and match evidence before selecting one.** |
| Low-confidence candidate | **Suggested match · {confidence} confidence**; action **Use this match**; do not auto-select |
| Offline with cached media | **Showing saved artwork. Last checked {date}.** |
| Stale or expired media | **This image is out of date and can’t be shown offline. Refresh it when a provider is available.** |
| Partial result | **Some game details are unavailable. You can retry them or keep playing.** |
| Provider request failure | **Artwork couldn’t be loaded. Retry when the provider is available, or keep playing without it.** |
| Unsupported/rejected local image | **This image can’t be used. Choose a PNG or JPEG image no larger than 20 MiB.** |
| Rights unavailable | **This provider image isn’t available for private offline use under the recorded terms. Choose another match or add your own image.** |
| Capacity refusal | **This media budget doesn’t have room for the selection. Reclaim provider media or lower the preparation selection.** |
| Provider attribution | **Game data and images from IGDB** with a static link to the provider and visible terms/cache policy details |
| Redistribution terms | **Available only in this private, authenticated library. Redistribution rights are not granted.** |
| Error remedy | State the affected artwork/metadata operation, then show **Retry** or the next available action. Never use error color or copy on Play/Continue because enrichment failed. |
| Destructive — remove private original | Confirmation title: **Remove private artwork?** Body: **This removes the selected original from your private library and its export. It does not affect the game or saved progress.** Buttons: cancellation-role **Keep artwork** (Escape invokes this same action) / **Remove Artwork** |
| Reclaim derived provider cache | Confirmation title: **Remove cached provider media?** Body: **This frees {size} from the artwork cache. Provider images may need to download again. Private artwork, games, and saves stay on this Mac.** Buttons: cancellation-role **Keep cached media** (Escape invokes this same action) / **Remove Cached Media** |
| Disable provider | **Turn off IGDB lookup? New and queued lookups will stop. Your selected metadata and private artwork will stay.** Buttons: cancellation-role **Keep IGDB enabled** (Escape invokes this same action) / **Turn Off** |

## Canonical UI element inventory

Accessibility identifiers below are required stable contracts, using the existing `playstead.game.{assetSetID}.*` and `playstead.settings.*` namespaces. The enclosing destination is an accessibility container with a concise label. Decorative art backgrounds, placeholders' redundant glyphs, and progress spinners are hidden when their state is already spoken in text.

| ID / accessibility identifier | Kind | Role and interaction | Required states |
|-------------------------------|------|----------------------|-----------------|
| `artwork-card` / `playstead.game.{id}.artwork` | media, list-collection, interactive-control | Truthful cover in the existing system identity slot; image itself is not a button | Missing monogram; loading; cached; cached offline; stale/expired; partial; ambiguous; rejected/rights-unavailable; failed; populated square/portrait/landscape |
| `game-title` / `playstead.game.{id}.summary` | static-content, list-collection, interactive-control | Existing title/system/readiness group and direct action | Existing readiness states remain authoritative; title absent uses existing filename-derived title with disclosure; long title wraps to two lines |
| `game-detail` / `playstead.game.{id}.details` | nav, static-content, media, interactive-control | More Actions item **View Game Details**, opens bounded native detail | Open/close; loading metadata; offline; provider failure; selection retained; focus restored |
| `description` / `playstead.game.{id}.description` | static-content | User or provider description with source | Empty; loading; populated; partial; offline; long text wraps and destination scrolls |
| `representative-screenshot` / `playstead.game.{id}.screenshot.featured` | media, static-content | Detail image with visible **Game screenshot** label | Empty; loading; cached offline; stale/expired; rejected; rights-unavailable; failed; populated |
| `screenshot-gallery` / `playstead.game.{id}.gallery` | list-collection, media, nav, interactive-control | Keyboard/controller/AX gallery traversal | Zero; one; many; loading; partial; failed; mixed ratios; long caption; visible Close and image count |
| `provider-consent` / `playstead.settings.metadata.consent` | form, static-content, interactive-control | Review exact query/disclosure, provider and rights before enabling | Disabled/default; incomplete credentials; enabled; pending cancellation; expired consent after changed fields/terms; privacy rejection |
| `match-candidates` / `playstead.game.{id}.matches` | list-collection, interactive-control, static-content | Explicit candidate selection with evidence/confidence | Zero; one; many; low confidence; ambiguous; selected; provider error; long result title |
| `local-media-form` / `playstead.game.{id}.media-editor` | form, media, interactive-control, static-content | Add local text/image to a named field | Unfilled; selected; uploading; accepted; partial; unsupported type; byte/dimension rejection; decode failure; retry/cancel |
| `metadata-corrections` / `playstead.game.{id}.corrections` | form, list-collection, interactive-control, static-content | Edit field and explicit per-field Reset to provider | Unchanged/provider; user-corrected; offline queued; refresh preserved; competing values; conflict resolved; long text |
| `delivery-preparation` / `playstead.settings.metadata.delivery` | form, list-collection, interactive-control, static-content | Minimal/Balanced choice and selected-game preparation review | Default Balanced; review; queued; running; partial; canceled; backoff; offline; quota/rights rejection; completed |
| `media-cache-controls` / `playstead.settings.metadata.cache` | list-collection, interactive-control, static-content | Independent 1 GiB per-user provider cache accounting, expiry and reclaim | Empty; under budget; at budget; capacity refusal; reclaimable; pinned; expired; reclaiming; failed; one/many media items |
| `metadata-settings-navigation` / existing `playstead.settings` | nav, list-collection, interactive-control | Metadata group inside existing Settings | Provider unavailable; credentials absent; provider enabled; loading; error; return to same settings row |
| `metadata-conflict` / `playstead.game.{id}.conflict` | list-collection, static-content, interactive-control | Show and resolve both incompatible values | Absent; one incoming value; multiple competing values; selected resolution; retry/sync pending |

All interactive controls use native buttons, menu items, toggles, or text fields with standard macOS roles and keyboard behavior. Each receives a meaningful accessible label/value and selected/disabled state, in addition to its stable identifier. Artwork announces game title, image role, and provenance without repeating the image's decorative glyph. Gallery actions expose image index and count; VoiceOver can move and close without keyboard/controller input.

| Category | Element(s) | Status | Observable resolution |

| populated | artwork card, detail, featured image, gallery, candidate list, preparation, cache | ✅ covered | Show truthful media at its preserved ratio, source/version and match evidence, attribution, and actual cache state; gallery shows an image count and game-image label. |

| long-text | game title, description, candidate title, provider terms, copy, corrections | ✅ covered | Card title clamps to 2 lines; detail/form text wraps and scrolls. Query and consent text remains selectable/readable; button labels use short verbs and retain their 44 pt targets. |
