## Accomplishments

- Added durable owner/game/provider/policy-keyed jobs with persisted queued, running, partial, canceled, complete, and error states; explicit selected-game estimates; authenticated idempotent API controls; consent checks before provider requests and evidence persistence; bounded retries honoring `Retry-After`; and serialized per-user/global admission limits. - Added a database-shared 4 requests/second schedule and an 8-job active queue, with no more than two active jobs for an owner. IGDB evidence now stores a 64 KiB-bounded description plus cover and screenshot references.

Reclaim tests compare canonical ROM, save, and private-original bytes before and after.
