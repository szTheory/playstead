## Accomplishments

- Added a fixed `https://api.igdb.com/v4/games` transport using the official `Client-ID` and bearer headers, a bounded title/system query, redirect and retry disablement, finite timeouts, a 1 MiB response cap, and at most ten candidates.
- Mapped only supported Game Boy, Game Boy Color, and Game Boy Advance system IDs. Candidate records include provider/version, title/platform evidence, confidence, attribution, terms URL, policy revision, cache expiry, and suggestion-only match kind. Hash lookup returns an explicit unsupported result.
- Added persistent owner-and-asset-scoped disclosure revisions, preview/readiness information, authenticated consent/search/revoke routes, and a recheck before evidence persistence. Disabled or stale consent reaches no provider transport.
- Kept provider images fail-closed unless the exact server-configured terms revision and private-owner scope are present. Private original metadata media stays available independently. Cache age is stored separately from the nullable license-expiry value.
- Added exact ExUnit manifest identities and an additive migration for consent and evidence. A follow-up idempotent migration adds terms columns for databases that had already applied the first migration during this execution.

## Decisions Made

- IGDB's official documentation specifies POST requests to `/v4/games`, `Client-ID` plus bearer authorization headers, and APICalypse query text in the request body. Search input is limited to the disclosed title and an explicit supported platform ID; no filename, content hash, local path, save bytes, or play history enters the request. [IGDB API documentation](https://api-docs.igdb.com/)
- IGDB documents free API use for noncommercial use under the Twitch Developer Services Agreement and directs commercial projects to a separate partnership process. The API shows that attribution and terms link; commercial hosting remains out of scope. [Twitch Developer Services Agreement](https://legal.twitch.com/legal/developer-agreement/)
- Candidate confidence describes title/platform evidence only. Every candidate remains a suggestion and cannot replace content identity or recognition evidence.
- No image-rights grant is inferred from API access. The lookup feature can operate with provider images disabled.
